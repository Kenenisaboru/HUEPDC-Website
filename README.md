# 🌱 Haramaya University Environmental Protection & Development Club (HUEPDC)

A modern, responsive website developed for the **Haramaya University Environmental Protection & Development Club (HUEPDC)**.  
The website aims to promote environmental awareness, sustainability, and community engagement through a clean and interactive user interface.

🔗 **Live Website:**  
https://huepdc-website12.netlify.app/

---

## 📌 Project Overview

This project was built to:
- Showcase the mission and activities of HUEPDC
- Raise awareness about environmental protection
- Provide information about events, programs, and club members
- Offer a modern digital presence for the club

---

## 🚀 Features

- 🌍 Responsive design (works on mobile, tablet, and desktop)
- 🎨 Modern UI with animations (Framer Motion)
- 📊 Data visualization using charts
- 📸 Image galleries
- 📬 Contact form integration
- ⚡ Fast performance and optimized build
- 🌐 Deployed on **Netlify**

---

## 🛠️ Technologies Used

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **Framer Motion**
- **React Icons**
- **Chart.js**
- **EmailJS**
- **Netlify (Deployment)**
